# AstroFix 🚀
### A Sci-Fi Puzzle Survival Adventure Game built with Unity

---

# 📖 About The Game

AstroFix is a third-person sci-fi puzzle survival adventure game where the player must restore critical systems inside a damaged space station while surviving dangerous environmental hazards and a hostile creature.

The player explores multiple interconnected rooms, solves system-based puzzles, restores power, oxygen, and fuel systems, and finally activates the station engine to return home safely.

The game combines:

- 🧩 Puzzle Solving
- 🚪 Exploration
- ⚠️ Survival Pressure
- 🌌 Environmental Storytelling
- ⏳ Timed Objectives
- 👾 Horror / Sci-Fi Atmosphere

# 🚀 Setup Instructions

## 1️⃣ Clone Repository

```bash
git clone https://github.com/vkc5/AstroFix-Game-Project.git
```

---

## 2️⃣ Open Project

Open:

```text
Unity Hub → Add Project → Select project folder
```

---

## 3️⃣ Open Main Scene

Recommended startup scene:

```text
Start Menu
```

---

## 4️⃣ Play The Game

Press:

```text
▶ Play
```

inside the Unity Editor.
